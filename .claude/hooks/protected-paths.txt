# Paths agents must not edit directly — consumed by .claude/hooks/guard-paths.sh.
#
# Format:  decision | glob | reason
#   decision  deny = blocked with the reason; ask = a human confirms the edit
#   glob      repo-relative; `*` also matches across `/`; a leading `**/` also matches at the root
#
# Special cases implemented in guard-paths.sh (not listed here):
#   - Accepted ADRs (docs/decisions/NNNN-*.md with "Status: Accepted") -> ask (ADRs are immutable)
#   - Existing email fixtures (fixtures/email/*.eml) -> ask (byte-exact conformance data)
#
# Every new line needs a test case in scripts/tests/test_hooks.py.

# --- Lockfiles: always produced by the package manager -------------------------------
deny | **/pnpm-lock.yaml   | Lockfiles are generated. Edit the manifest and run the package manager (via scripts/setup).
deny | **/package-lock.json | Lockfiles are generated. Edit the manifest and run the package manager (via scripts/setup).
deny | **/yarn.lock        | Lockfiles are generated. Edit the manifest and run the package manager (via scripts/setup).
deny | **/bun.lock         | Lockfiles are generated. Edit the manifest and run the package manager (via scripts/setup).
deny | **/bun.lockb        | Lockfiles are generated. Edit the manifest and run the package manager (via scripts/setup).
deny | **/pubspec.lock     | Lockfiles are generated. Edit pubspec.yaml and run the package manager (via scripts/setup).
deny | **/Cargo.lock       | Lockfiles are generated. Edit Cargo.toml and run cargo.
deny | **/composer.lock    | Lockfiles are generated. Edit composer.json and run composer.
deny | **/Podfile.lock     | Lockfiles are generated. Run pod install.
deny | **/Gemfile.lock     | Lockfiles are generated. Run bundle install.
deny | **/go.sum           | Generated by the Go toolchain. Run go mod tidy.
deny | **/gradle.lockfile  | Generated by Gradle dependency locking.

# --- Generated source: edit the input and re-run codegen -------------------------------
deny | **/*.g.dart          | Generated code. Edit the annotated source and re-run code generation.
deny | **/*.freezed.dart    | Generated code. Edit the annotated source and re-run code generation.
deny | **/*.generated.*     | Generated code. Edit the generator input and re-run code generation.
deny | **/__generated__/*   | Generated code. Edit the generator input and re-run code generation.

# --- Guardrails and CI: a human must confirm ---------------------------------------------
ask  | .claude/settings.json | This changes agent permissions/hooks for everyone. A human must confirm guardrail changes.
ask  | .claude/hooks/*       | This changes agent guardrails. A human must confirm, and scripts/tests/test_hooks.py must cover it.
ask  | .githooks/*           | This changes git hooks (secret scan, commit checks). A human must confirm.
ask  | .github/workflows/*   | CI workflows run with repository credentials. A human must confirm workflow changes.
ask  | .github/CODEOWNERS    | Ownership rules decide who must review. A human must confirm.
