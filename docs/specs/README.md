# Specs

A spec describes **what** a feature does and **why**, with numbered, testable acceptance criteria.
Create one with `/spec`. Specs are numbered `NNNN-slug.md`, starting from [template.md](template.md).

Lifecycle: `Draft` → `Approved` (by a human) → `Implemented` (once all its issues have shipped).
Breaking a spec into issues happens with `/breakdown`.
